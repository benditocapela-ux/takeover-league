Vollständige Login-Sperre – nur manuell

Die Deaktivierung eines Profils sperrt Daten und Funktionen, nicht die Anmeldung. Um eine Person auch am Login zu hindern, kann der Admin in der Supabase-Konsole auth.users.banned_until setzen. Diese Befehle werden hier niemals ausgeführt. Der Platzhalter ist vor einer bewussten manuellen Ausführung zu ersetzen.

Login sperren

update auth.users set banned_until = now() + interval '100 years'
where email = '<email>';

Sperre aufheben

update auth.users set banned_until = null
where email = '<email>';
